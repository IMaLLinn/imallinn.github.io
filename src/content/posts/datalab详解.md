Data Lab 给了一组 C 函数骨架，让我在有限的运算符和常量下补出整数运算，再用整数位模式表示浮点结果。整数题按 32 位补码和算术右移来推。我先从取字节和移位入手，这两题能直接看出输入和掩码各留下了哪些位。

## 掩码先画出要保留的位

| 问题 | 位上的做法 |
| --- | --- |
| `bitAnd` | 用德摩根定律把与改写为 `~(~x \| ~y)` |
| `getByte` | 右移 `n << 3`，再用 `& 0xFF` 留下一个字节 |
| `logicalShift` | 算术右移后，清掉高位补出的符号位 |
| `fitsBits` | 左移 `32 - n` 再算术右移，检查能否回到原值 |
| `ilog2` | 用 16、8、4、2、1 位逐段查找最高位的 1 |

取字节只保留最低 8 位。做 `logicalShift` 时，同样先算术右移，但得留下低位中全部有效的结果。直接拿最高位右移再取反，会把本应保留的最高一位也清掉。实现里多做一次左移，掩码写成 `~(((1 << 31) >> n) << 1)`。按题设机器模型推，`n = 0` 时掩码全 1，`n = 31` 时只保留最低一位。用 `0x80000000` 检查这两端，应分别得到原值和 1。

到了 `bitCount`，掩码还可以用来隔开计数。以低四位 `1011` 为例，先分别数 `10` 和 `11`，得到 1 和 2，再把两个计数合成 3。代码用 `0x55` 累加相邻两位，用 `0x33` 合并成四位组，再逐步累加到 8、16、32 位。

```c
int bitCount(int x) {
    int m1 = 0x55 | (0x55 << 8);
    int m2 = 0x33 | (0x33 << 8);
    int m4 = 0x0F | (0x0F << 8);
    int m8 = 0xFF | (0xFF << 16);
    int m16 = 0xFF | (0xFF << 8);

    m1 = m1 | (m1 << 16);
    m2 = m2 | (m2 << 16);
    m4 = m4 | (m4 << 16);

    x = (x & m1) + ((x >> 1) & m1);
    x = (x & m2) + ((x >> 2) & m2);
    x = (x + (x >> 4)) & m4;
    x = (x + (x >> 8)) & m8;
    return (x + (x >> 16)) & m16;
}
```

## 补码的边界比正数样例有用

同样是右移，到了 `divpwr2` 就有舍入的坑。算术右移会让 `-3 >> 1` 得到 −2，题目要的是向零截断的 −1。负数要先加偏移量 $2^n-1$，例如先把 −3 加 1 再右移。用 `x >> 31` 得到全 0 或全 1，再与偏移量做与，正数和零就自然加 0。

`bang` 用补码取负 `~x + 1`。除了零，`x` 和它的补码取负结果至少有一个最高位为 1。最小补码整数的两者相同，但最高位仍为 1。判断正数则还要排除零。比较 `x <= y` 时，异号先看符号，同号再看 `y - x` 的符号，免得误用异号相减的符号位。

## 单精度真正容易错在舍入

整数转单精度时，先找绝对值的最高位 $k$，阶码是 $k+127$。最高位是规格化数隐含的 1，尾数字段取它右侧的 23 位。能装下就左对齐并补零，装不下就比较舍弃部分与半个单位。正好一半时，只有保留部分是奇数才进位。尾数进位溢出，还得给阶码加一。

```c
unsigned float_i2f(int x) {
    if (x == 0) return 0;
    unsigned sign = (unsigned)x & 0x80000000u;
    unsigned value = sign ? ~(unsigned)x + 1u : (unsigned)x;
    int msb = 31;
    while ((value & (1u << msb)) == 0) msb--;

    unsigned exp = msb + 127;
    unsigned frac;
    if (msb <= 23) {
        frac = (value << (23 - msb)) & 0x7FFFFFu;
    } else {
        int shift = msb - 23;
        frac = (value >> shift) & 0x7FFFFFu;
        unsigned lost = value & ((1u << shift) - 1);
        unsigned half = 1u << (shift - 1);
        if (lost > half || (lost == half && (frac & 1))) {
            frac++;
            if (frac >> 23) {
                exp++;
                frac &= 0x7FFFFFu;
            }
        }
    }
    return sign | (exp << 23) | frac;
}
```

取绝对值前先转成无符号，最小的 `int` 也不用在有符号范围里求反。舍入规则可以拿 16,777,217 检查，它正好夹在单精度可表示的 16,777,216 和 16,777,218 中间，应选保留位为偶数的 16,777,216。

单精度的另两题也沿用这三个字段。取负时只翻符号位，NaN 按题意原样返回。乘二时，非规格化数移尾数，规格化数加阶码，阶码溢出就清零尾数得到无穷大。乘二遇到全 1 阶码的 NaN 和无穷大则原样返回。
