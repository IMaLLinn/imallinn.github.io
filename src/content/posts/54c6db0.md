我把这篇当速查表，先记引用类型和对象类型各管什么，再按需求选集合。

## 编译看引用，重写看对象

`Animal pet = new Cat()` 中，编译器按 `Animal` 判断哪些成员可以调用。实例方法被重写后，运行时由实际对象 `Cat` 决定执行哪一版。静态方法属于类，子类同名方法会隐藏父类版本。字段访问也按引用类型解析。需要访问子类独有的成员时，先用 `instanceof` 检查再转型。

```java
class Main {
    static class Animal {
        void speak() {
            System.out.println("animal");
        }
    }

    static class Cat extends Animal {
        @Override
        void speak() {
            System.out.println("meow");
        }
    }

    public static void main(String[] args) {
        Animal pet = new Cat();
        pet.speak(); // meow
    }
}
```

构造时，`this(...)` 委托同类的另一个构造器，`super(...)` 调父类构造器。父类缺无参构造器时，要保证构造链显式调用一个存在的父类构造器。抽象类适合共享实现，接口适合约定能力。引用加 `final` 后不能重新赋值，对象内部仍可能可变。

## 集合按访问方式挑

| 要做的事 | 常用类型 | 容易漏的细节 |
| --- | --- | --- |
| 按下标取，允许重复 | `ArrayList` | 中间插删可能要搬元素 |
| 去重或保留插入顺序 | `HashSet` / `LinkedHashSet` | 自定义对象按内容去重时同时重写 `equals` 和 `hashCode` |
| 按键查找 | `HashMap` | 同一个键再次写入会覆盖旧值 |
| 按键排序 | `TreeMap` | 顺序由键的比较规则决定 |

## 异常在签名里怎么看

`throw` 扔出一个异常对象，`throws` 在签名上声明可能抛出的异常。`IOException` 这类受检异常要捕获，或交给调用者处理。`NullPointerException` 属于运行时异常，编译器不会强制声明。
